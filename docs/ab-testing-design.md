# 昆曲VR剧场 · A/B 测试方案

## 1. 实验目标

验证不同数字化表达方式对**昆曲文化传播效果**的影响，重点回答：

1. 交互叙事是否比线性叙事更有利于文化理解与记忆？
2. 参与式沉浸是否显著优于纯观赏模式？
3. 嵌入文化阐释（虚拟 NPC 讲解）是否提升跨文化受众的理解度？

---

## 2. 实验变量设计

### 2.1 变量矩阵

| 变量维度 | 版本 A（对照） | 版本 B（实验） | 测试目的 |
|----------|----------------|----------------|----------|
| **叙事方式** | 线性叙事（按时间顺序呈现昆曲发展） | 交互叙事（用户选择影响叙事走向） | 验证交互叙事 vs 线性叙事的传播效果差异 |
| **沉浸程度** | 纯观赏模式（被动观看） | 参与式模式（可互动、可影响剧情） | 验证参与感对文化理解的影响 |
| **文化阐释** | 无阐释（纯体验） | 嵌入文化引导模块（虚拟 NPC 讲解） | 验证文化阐释对跨文化理解的作用 |

### 2.2 变量 operationalization（操作化定义）

#### 叙事方式

| | 版本 A：线性叙事 | 版本 B：交互叙事 |
|---|------------------|------------------|
| **路径** | 戏园 → 茶楼 → 园林 → 数字剧场（固定顺序） | 入口选择“学戏/观戏/游园”决定首场景与分支 |
| **分支** | 无 | ≥3 个关键节点（茶楼是否进后台、园林是否对唱、结尾回顾侧重） |
| **时长** | 各场景时长相等 | 总时长相当，分支场景互斥填充 |

#### 沉浸程度

| | 版本 A：纯观赏 | 版本 B：参与式 |
|---|----------------|----------------|
| **乐器** | 禁用，仅观看 | 可拨琵琶、击鼓伴奏 |
| **对唱** | 禁用 | 园林《惊梦》可选对唱 |
| **剧情影响** | 演出流程固定 | 互动成功改变演员动画/解锁隐藏内容 |
| **移动** | 预设轨道或固定视点 | 自由漫游 + 就座选择 |

#### 文化阐释

| | 版本 A：无阐释 | 版本 B：NPC 讲解 |
|---|----------------|------------------|
| **NPC** | 仅动作引导，无讲解文本/语音 | 引路人 NPC 在场景切换时插入文化知识点 |
| **触发** | — | 凝视热点 3 秒或完成互动后自动弹出 |
| **内容** | — | 每场景 2–3 条：历史背景、术语解释、美学要点 |
| **多语言** | — | 中文 + 英文（跨文化子样本专用） |

## 3. 实验设计

### 3.1 设计类型

采用 **2×2×2 全因子设计**（8 组），或分阶段 **单因子轮换** 以降低样本需求：

**推荐：分阶段单因子 A/B**

| 阶段 | 控制变量 | 测试因子 | 样本量/组 |
|------|----------|----------|-----------|
| 实验 1 | 沉浸=参与式，阐释=有 | 叙事方式 | n ≥ 60 |
| 实验 2 | 叙事=交互，阐释=有 | 沉浸程度 | n ≥ 60 |
| 实验 3 | 叙事=交互，沉浸=参与式 | 文化阐释 | n ≥ 80（含 50% 国际用户） |

### 3.2 分组与随机化

```
用户登录/启动 → 哈希(userId + experimentId) mod 2 → 分配 A/B
                ↓
         加载 experience-config.json
                ↓
         上报 session_start { variant, factors[] }
```

- **分层随机**：按年龄、昆曲接触史、文化背景（本土/国际）分层
- **排除**：前 24 小时内重复参与者；严重晕动症退出者单独记录

## 4. 评估指标

### 4.1 一级指标（传播效果）

| 指标 | 测量方式 | 假设方向 |
|------|----------|----------|
| **文化知识增益** | 体验前后测（10 题选择题 + 2 题开放） | B > A |
| **文化认同/兴趣** | Likert 7 点量表（4 项） | 参与式、有阐释组更高 |
| **记忆保持** | 7 天后追测（子样本 30%） | 交互叙事组更高 |
| **分享意愿** | 是否生成并分享“昆曲印记” | 参与式组更高 |

### 4.2 二级指标（过程行为）

| 指标 | 数据源 | 说明 |
|------|--------|------|
| 完成率 | `session_end` | 是否体验全程 |
| 互动次数/时长 | `interaction_complete` | 参与深度 |
| 分支覆盖率 | `narrative_choice` | 交互叙事探索度 |
| NPC 讲解触达率 | `cultural_npc_view` | 阐释模块有效性 |
| 晕动症评分 | 体验后 SSQ 简版 | 控制变量 |

### 4.3 跨文化子研究（实验 3 专项）

| 指标 | 版本 A | 版本 B |
|------|--------|--------|
| 术语理解度 | 体验后测（工尺、行头等） | 同上 |
| 美学感知 | IPA 量表（意境、程式化等） | 同上 |
| 开放编码 | “用一句话描述昆曲” | 主题分析 |

**假设**：文化阐释 B 版对国际用户的知识增益效应量显著大于本土用户。

---

## 5. 前后测问卷结构（摘要）

### 5.1 前测（5 分钟）

- 人口学：年龄、教育、语言背景
- 昆曲接触史：观看次数、学习经历（0–4 级）
- 基线知识：10 题（约 40% 用户应答对，避免天花板）

### 5.2 后测（8 分钟）

- 同 10 题知识题（含 2 题转移题）
- 兴趣与认同量表
- 体验满意度与推荐意愿（NPS）
- 开放题：“印象最深的一个场景/概念”

### 5.3 7 日追测（线上，3 分钟）

- 知识题子集（5 题）
- 是否进一步检索昆曲相关信息（行为自报）

## 6. 统计分析方法

| 对比 | 方法 | 显著性 |
|------|------|--------|
| 叙事 A vs B | 独立样本 t 检验 / Mann-Whitney U | α = 0.05 |
| 沉浸 A vs B | 同上 + 协变量（前测知识） | ANCOVA |
| 阐释 A vs B | 同上，分组：本土 vs 国际 | 交互效应检验 |
| 多因子 | 实验 8 组全因子 | 三因素 ANOVA |

**效应量**：报告 Cohen's d 或 η²，最小可检测效应 d = 0.5（power = 0.8）。

## 7. 实验伦理与质控

| 项目 | 措施 |
|------|------|
| 知情同意 | 启动前 MR 界面展示，语音+手势确认 |
| 数据隐私 | 语音仅用于实时评分，不存储原声；userId 哈希 |
| 设备卫生 | 一次性面罩；体验间隔清洁 |
| 晕动症 | 随时长按菜单退出；退出不计入完成率分母 |
| 对照污染 | 不同组使用不同配置 ID，内容资产隔离 |

## 10. 预期结论与应用

- 若 **交互叙事 + 参与式** 显著优于线性观赏：正式版默认采用 G7/G8 配置
- 若 **文化阐释** 仅对国际用户有效：部署地域化配置（国内精简阐释，海外完整 NPC）
- 负向结果（如无显著差异）同样有价值：指导资源投向场景质量而非交互复杂度

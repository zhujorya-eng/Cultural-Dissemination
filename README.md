# 昆曲 VR 剧场

沉浸式 Web VR 昆曲文化体验平台，以《牡丹亭》为蓝本，让观众从"旁观者"变为"参与者"。

## 功能特色

- **四大场景**：序厅雅集、古戏台赏曲、江南园林游园、后台妆奁
- **VR 沉浸**：基于 WebXR，支持 VR 头显一键进入虚拟剧场
- **互动演出**：古戏台场景可启动《游园惊梦》折子戏，含水袖表演动画与唱词字幕
- **文化导览**：每个场景配有昆曲历史、艺术特色的科普面板
- **自由漫游**：鼠标/触控拖拽旋转视角，滚轮缩放

## 技术栈

- React 19 + TypeScript + Vite
- Three.js + React Three Fiber + @react-three/xr
- WebXR API

## 快速开始

```bash
npm install
npm run dev
```

浏览器访问 `http://localhost:5173`，点击「步入剧场」开始体验。

### VR 模式

使用支持 WebXR 的 VR 头显（如 Meta Quest），点击右下角「Enter VR」按钮进入沉浸式体验。

## 场景说明

| 场景 | 内容 |
|------|------|
| 序厅 | 昆曲六百年源流介绍 |
| 古戏台 | 传统戏台建筑 + 杜丽娘水袖表演 |
| 园林 | 《游园惊梦》江南园林意境 |
| 后台 | 脸谱、服饰、道具展示 |

## 文化传播

本项目为 **Cultural-Dissemination** 文化传播系列的一部分，旨在通过数字技术活化非遗，降低年轻群体认知门槛，推动昆曲艺术的当代传播。

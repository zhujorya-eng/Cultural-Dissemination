# Cultural-Dissemination · 数字昆曲

围绕昆曲精神内核进行跨文化价值提炼，并以数字技术打造面向全球受众的戏曲传播新形态。

## 项目文档

- [数字昆曲：精神内核价值提炼与数字产品设计](./docs/数字昆曲-价值提炼与产品设计.md)

## 核心框架

| 维度 | 说明 |
|-----|-----|
| 东方审美 | 水磨腔、程式、服饰、留白舞台的跨文化视觉转译 |
| 人物情感 | 以普世情感标签建立共情，降低唱词依赖 |
| 人文精神 | 传承、情礼之辨、生命态度的深度内容 |
| 传统礼乐 | 礼序、曲牌、行当协作的可视化与互动体验 |

## 数字产品模块

- 高清数字修复 · AI 数字人曲师 · 虚拟舞台
- 互动短视频 · 多语种字幕 · 人物故事动画
- 幕后纪录片 · VR 数字剧场 · 沉浸式戏曲体验
